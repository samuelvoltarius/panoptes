# Security / Sicherheit

**Deutsch:** Wenn du eine Sicherheitslücke in Panoptes findest, melde sie bitte **nicht** öffentlich als Issue, sondern per E-Mail an **office (at) photo-aigner.at** mit dem Betreff „Panoptes Sicherheit“. Beschreibe kurz, was betroffen ist und wie man es nachstellen kann. Wir melden uns, sobald wir es geprüft haben. Panoptes ist ein Freizeitprojekt, deshalb gibt es keine feste Antwortzeit und kein Bug-Bounty.

**English:** If you find a security issue in Panoptes, please do **not** open a public issue. Instead, e-mail **office (at) photo-aigner.at** with the subject "Panoptes security". Briefly describe what is affected and how to reproduce it. We will get back to you once we have looked into it. Panoptes is a hobby project, so there is no fixed response time and no bug bounty.

Bitte teste nur an deinem eigenen Auto und mit deinem eigenen Konto. / Please test only on your own car and with your own account.
